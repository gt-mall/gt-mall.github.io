## 三端各司其职

GT-Shop 使用单一 Git 仓库。Go 后端统一承载业务 API，React 服务运营管理，UniApp 服务微信小程序和 H5 用户端。

| 部分            | 技术                                | 主要职责                           |
| --------------- | ----------------------------------- | ---------------------------------- |
| `admin-server/` | Go、Gin、GORM、MySQL                | 商品、交易、权限、任务与接口       |
| `admin-web/`    | React、TypeScript、Ant Design、Vite | 商品运营、订单售后、会员与经营分析 |
| `miniapp/`      | UniApp、Vue 3、TypeScript、Pinia    | 浏览、选购、购物车、订单与售后     |

管理端页面可嵌入后端程序。业务代码按商品、订单、会员、系统等领域组织，默认沿用路由、API、Service 和数据库这条直接的调用路径。

## 后端目录

```text
admin-server/
├── routers/          路由注册与鉴权中间件
├── internal/
│   ├── product/      商品、分类、SKU、库存、运费
│   ├── order/        后台订单、售后与退款协调
│   ├── member/       会员管理
│   ├── system/       用户、角色、权限、设置、文件
│   ├── dashboard/    运营看板
│   ├── analytics/    经营分析
│   ├── miniapp/      用户端业务 API
│   ├── model/        数据库模型
│   └── query/        生成的数据库查询代码
├── bootstrap/        配置、迁移、Seed 与缓存初始化
├── pkg/              跨业务公共工具
├── data/             Migration 与 Seed
├── docs/             后台 API 文档
├── docs-miniapp/     用户端 API 文档
└── test/             后端测试
```

小程序接口统一使用 `/api/miniapp/*`，有独立 Swagger 文档，直接调用后端业务能力。

## 前端目录

管理端的 `src/framework/` 提供路由、HTTP、登录和权限能力；`src/modules/` 保存业务页面；`src/shared/` 放跨业务复用组件、Hooks 和工具。

用户端的 `src/pages/` 提供页面，`src/api/` 按业务组织接口，`src/services/` 处理请求与会话，`src/stores/` 保存会员、购物车和公共配置状态。

## 从下单到履约

```text
浏览商品 → 选择 SKU → 创建订单与锁定库存
                        ↓
                 微信预支付与付款
                        ↓
            签名回调 / 服务端查单确认
                        ↓
             支付后扣减 → 发货 → 收货
                        ↓
                评价 / 申请售后
```

未付款订单的超时关闭、支付结果核对、自动收货与退款核对由固定后台任务推进。任务状态保存在数据库，多实例通过 MySQL 租约协调执行。

## 金额与库存

金额以元为单位存入 `DECIMAL`；业务计算使用整数分或十进制工具。API 用十进制字符串传递金额，前端沿用明确的单位和精确计算工具。

库存区分实物库存和锁定库存。**可售库存 = 实物库存 − 锁定库存**。下单、支付、取消和售后各有库存变动路径，流水记录变动前后数值与操作信息。

## 缓存与接口契约

商品静态信息可以使用 Redis Cache Aside 缓存，请求合并减少并发重复查询。商品变化后切换缓存世代，实时库存单独查询；缓存异常有数据库回源路径。

后台 API 从 Go DTO、路由与 Swagger 注解生成，再生成管理端 TypeScript Client。菜单、路由和按钮消费统一权限 code，敏感操作由后端最终校验。

## AI 能力边界

三端项目 Skills 已随源码提供，帮助 AI 编码助手理解规范。AI 用户画像、推荐优惠券与个性化定价仍在开发中；当前版本没有完整的个性化运营闭环。
